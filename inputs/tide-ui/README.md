# 任务：给《潮汐记事》出一套完整 UI 风格规范

## 这是什么

《潮汐记事》（工程名 tide）是一个用 **Godot 4.7.2** 做的中式渔村小游戏，1280×720，`stretch/mode = canvas_items`。

玩家在两个场景里活动：

- **岸上**（`shore.tscn`）：WASD 走动，走近 NPC 会主动搭话，F 送鱼，E 卖鱼/上船，R 买饵。
- **海上**（`main.tscn`，主场景）：W 前进 S 后退 A/D 转向，空格抛竿/收线，E 上岸，R 买饵，T 读信，ESC 退出。

美术方向是低多边形 3D + 手绘感，光线按时段变化（晨/午/暮/夜）。**但 UI 完全没有设计过**：所有界面都是代码里 `Label.new()` + `StyleBoxFlat.new()` 硬拼出来的，配色和字号是写得顺手就地填的，没有 Theme 资源，没有 token，也没有 hover/pressed 这些状态。

现在要的就是把这个缺口补上。

## 你要产出什么

在 `design/tide-ui/` 下交四样东西，缺一不可：

### 1. `UI-SPEC.md`

一份能被人照着执行的规范，不是设计感想。至少包含：

- **风格总纲**：一句话说清这套风格是什么，三个形容词，一段对照说明它和现有视觉（深墨底 + 铜色细边 + 米白字）是什么关系——延续、修正还是推翻，都要给理由。
- **色彩 token 表**：每个 token 一行，名字 / hex / 用在哪儿 / 什么场合不许用。至少覆盖：底色、面板底、描边、分隔线、主文本、次要文本、强调/高亮、警示、成功、夜色叠加。
- **字阶**：每级的字号 / 行高 / 字重 / 用途；中文字体栈（必须能显示中文，不许引入带版权风险的字体文件）。
- **间距、圆角、描边宽度、阴影**：给一套固定档位，别写"视情况"。
- **动效**：面板进出、文字浮现、按钮反馈的时长和缓动。
- **每个界面一节**：线框（尺寸标注，1280×720 坐标）+ 元素清单 + 每个元素的状态（normal / hover / pressed / disabled / focus，适用哪些写哪些）。

### 2. `tokens.json`

和 SPEC 一一对应的机器可读版本。每个颜色/字号/间距一个键，键名和 SPEC 里的 token 名完全一致。

### 3. `theme.tres`

**Godot 4 的 Theme 资源文件**，能被 `godot --headless --quit --path <项目>` 直接加载不报错。把能进 Theme 的东西都放进去：`StyleBoxFlat`、字号、字体颜色。代码里现在硬编码的 `Color(0.065, 0.080, 0.095, 0.82)` 这类值，应该能在 Theme 里找到对应的那条。

### 4. `prototype.html`

单文件，零外部依赖（不能有 CDN、不能有远程字体），双击就能在浏览器里打开。要求：

- 1280×720 画布，把现有全部界面按真实比例排出来
- 顶部能切换：岸上 / 海上 × 晨 / 午 / 夜
- 每个可交互元素有 hover 和 pressed 效果，鼠标能试
- 界面上的文案用现在真实的文案（见 `ui-inventory.md`），不要 Lorem ipsum

## 必须覆盖的界面

现有 5 个面（细节见 `ui-inventory.md`，代码摘录见 `code/`，截图见 `shots/`）：

1. 岸上主视图（顶栏 + 状态行 + 提示行 + 交互提示）
2. 海上主视图（顶部操作条 + 状态行 + 居中状态大字）
3. 底部对话面板（谁在说话 / 说了什么）
4. 信纸面板（读信用，米白纸面）
5. 交互提示与状态大字（"按 F 把鱼送给 阿鲛" 这类）

另外补齐现在**缺**的三个，这三个是设计的主要发挥空间：

6. 钓到鱼的结算卡（鱼名、长度、进了鱼篓几条）
7. 暂停 / 设置面板
8. 鱼篓或物品栏

## 硬约束

- **不改玩法、不改场景布局、不动 `art/` 里的模型和贴图**。这是纯 UI 层的活。
- **完全离线**：四份产出不许依赖任何外部服务、CDN、在线字体。
- **中文优先**：所有界面文案是中文，字体栈必须能正常显示，行高要为中文留够。
- **可缩放**：1280×720 是基准，放大到 1920×1080 时 UI 不能糊、不能挤。
- **可验收**：SPEC 里不许出现"适当""看情况""再调调"这类没法判定的说法。每个决策都要么给了具体值，要么给了判定标准。
- **不开 PR 合并**：做完开 PR，等人工审。

## 验收标准（由请求方逐条判定）

1. 四份文件都在 `design/tide-ui/` 下，README 式导览能看懂从哪看起。
2. `theme.tres` 在 Godot 4.7.2 里能 load，不报错、不警告缺资源。
3. `prototype.html` 断网、双击、能开，切换场景和时段有变化，交互元素有反馈。
4. `tokens.json` 能被脚本直接读，键名和 SPEC 一致，没有 SPEC 里没解释的野键。
5. 八个界面都覆盖到，每个界面至少列了该有的状态。
6. 能用一句话说清这套风格是什么，且这句话和 prototype 里看到的对得上。
7. SPEC 里每条决策都能被判定对错，没有含糊表述。
