# 《潮汐记事》UI 规范 · 基本盘 v1

定稿对象：Godot 4.7.2 工程，1280×720 画布，`stretch/mode = "canvas_items"`。
本文件是**唯一口径**。实现时任何一处与本文件不一致，要么改实现，要么先改本文件。

---

## 0. 这份基本盘怎么用

- 第 1–6 节是**底座**：所有元素共享的尺度、颜色、字、边、影、动效。
- 第 7–12 节是**逐元素规格**：每个面板、每一行、每个键帽的坐标、内边距、四角、四边、各状态色。
- 第 13 节是 Godot 映射，第 14 节是可量测的验收清单。
- 设计原则一句话：**常驻信息像焊在船板上的铜牌，瞬时反馈像雾里的一盏灯。**

三条硬规则（违反即视为没按本规范做）：

1. **左 2 上右下 1**：任何带铜边的面板，左侧描边 2px，其余三边 1px。这是全游戏的识别标记，不许改。
2. **一个界面只有两种色系**：深色 UI（墨 + 铜 + 雾白）与浅色纸（纸米 + 墨蓝 + 纸纹）。信纸是唯一的浅色面，其余一律深色，不许混。
3. **字号只从阶梯里取**：12 / 14 / 16 / 18 / 22 / 26 / 34。没有 13、15、19、20、21、24。

---

## 1. 尺度与栅格

- 基准栅格 **4px**。所有坐标、尺寸、间距、描边、圆角、位移都必须是 4 的倍数（圆角 3px 是唯一例外，见 §4）。
- 安全区：左 **24**、上 **24**、右 **24**、下 **24**。安全区外不放任何常驻元素。
- 间距阶梯：**4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64**。禁止 6、10、18、30 这类值。
- 面板内边距：小件 **12**，正文面板 **16**，纸面面板 **40**。

## 3. 字体

| 角色 | 字体族 | 用途 |
|---|---|---|
| 叙事 | `Noto Serif SC` → `Source Han Serif SC` → `Songti SC` → serif | 对话台词、信纸正文、结算鱼名、标题 |
| 界面 | `Noto Sans SC` → `Source Han Sans SC` → `PingFang SC` → `Microsoft YaHei` → sans | 状态数值、键帽、菜单、页脚、单位 |

字号阶梯 + 行高 + 字距：

| token | px | 行高 | 字距 | 用途 |
|---|---|---|---|---|
| `micro` | 12 | 16 | 0.5px | 键帽字、角标、"已送" |
| `meta` | 14 | 20 | 0.2px | 单位、页脚、操作条按键、副信息 |
| `label` | 16 | 22 | 0 | 面板名、页眉、提示 |
| `body` | 18 | 27 | 0 | 对话台词、信纸正文、菜单项 |
| `h2` | 22 | 30 | 0 | 状态行、抽屉标题、暂停标题 |
| `h1` | 26 | 33 | 0 | 瞬时大字、结算鱼名 |
| `display` | 34 | 40 | 0 | 换日 / 章节级大字（每屏最多一次） |

- 阿拉伯数字一律用等宽数字（`tabular-nums`），字号同上，**不改字距**。
- 中文标点用全角；数字与中文之间空 **0** 格（原文案 `第 1 天` 保留空格是文案规范，见 §13）。
- 没有字体文件时的降级：界面族降级到系统黑体，叙事族降级到系统衬线；**不许**因此改变字号与行高。

## 4. 描边 / 圆角 / 阴影

### 4.1 描边

| token | 值 | 用途 |
|---|---|---|
| `hair` | 1px | 所有面板的上/右/下边、分隔线 |
| `hair-accent` | 2px 左侧 | 面板左侧强调条（硬规则 1） |
| `focus` | 1px + 2px 外发光 | 焦点环 |

颜色：常驻面板 `copper-a42`；激活/聚焦 `copper-a72`；分隔线 `copper-a22`；纸面分隔 `paper-rule` 1px。

### 4.2 圆角

| token | 值 | 用途 |
|---|---|---|
| `r-key` | 3px | 键帽、角标、滑块旋钮容器 |
| `r-panel` | 3px | 所有面板（保持"手焊铁片"的手感，不要大圆角） |
| `r-paper` | 2px | 信纸（纸是切的，不是铸的） |
| `r-pill` | 999px | 只用于滑块旋钮（真圆） |

四角一律同值，**禁止单角异形**。

### 4.3 阴影

| token | 值 | 用途 |
|---|---|---|
| `shadow-panel` | `0 6px 18px rgba(0,0,0,0.45)` | 悬浮面板（对话、结算、暂停） |
| `shadow-paper` | `0 12px 28px rgba(0,0,0,0.45)` | 信纸 |
| `shadow-text` | `0 1px 2px rgba(0,0,0,0.60)` | 压在世界上的一切文字 |
| `shadow-text-strong` | `0 1px 3px rgba(0,0,0,0.80)` | 夜间 / 雾天文字 |
| `glow-focus` | `0 0 0 2px rgba(232,176,75,0.18)` | 焦点外发光 |

面板阴影不描边替代，二者同时存在。

## 5. 动效

| token | 值 |
|---|---|
| `dur-fast` | 120ms |
| `dur-base` | 180ms |
| `dur-slow` | 260ms |
| `hold-msg` | 2200ms（瞬时大字） |
| `hold-catch` | 2600ms（结算卡） |
| `ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` |

规则：

- 面板入场：透明度 0→1 + 位移 8px→0，`dur-slow`。
- 面板出场：透明度 1→0，`dur-base`，不做位移。
- 文字打字机效果**不要**（叙事节奏靠停留时长控制，不靠逐字）。
- 呼吸类（"继续"三角、"新记录"角标）周期 1600ms，透明度 0.55↔1.0，`ease` 往返。
- 任何动效都不得让文字在移动中不可读：位移上限 12px。

## 6. 键帽与图标

游戏本体没有按钮，全部交互是按键 → 必须给按键一个**看得见的样子**。

### 键帽（Keycap）

| 项 | 值 |
|---|---|
| 高 | 22px |
| 最小宽 | 22px |
| 内边距 | 水平 6px，垂直 0 |
| 圆角 | 3px |
| 底 | `ink-850` |
| 边 | 1px `copper-a42` |
| 字 | `micro` 12px / `fog-100` / 字距 0.5px / 界面族 |
| 下沿 | 内阴影 `inset 0 -1px 0 rgba(0,0,0,0.45)` 表现厚度 |
| 按下态 | 整体下移 1px，底 `ink-700`，边 `copper-a72` |
| 禁用态 | 底 `ink-900`，边 `copper-a22`，字 `fog-500` |

组合：键帽之间 gap **4px**；组合与组合之间 gap **16px**；组合与说明文字之间 gap **6px**。
操作条里的写法：`[W][A][S][D]` + 空格 + `走` + 24px 间隔 + `[F]` + `送鱼` ……

### 光标

- 游戏内不显示系统鼠标。需要指向的地方（原型里）用 1px 铜色十字，长 12px，中心留 4px 空。

## 7. 布局分区

屏分四区，互不重叠：

| 区 | 位置 | 内容 | 层级 |
|---|---|---|---|
| 常驻区 | 左上 (24,24) 起 | 操作条 → 状态行 → 交互提示，竖排 | z=10 |
| 瞬时区 | 水平居中，y=400 起 | 瞬时大字（抛竿、咬钩、换日） | z=20 |
| 叙事区 | 底部 (24, 720−24−H) | 对话面板 | z=30 |
| 覆盖层 | 全屏 / 右侧 / 居中 | 鱼篓抽屉 z=40、信纸 z=45、暂停 z=50、遮罩 z=44 | 见括号 |

常驻区三段之间的间距：操作条 → 状态行 **12**；状态行 → 交互提示 **8**。

## 10. 光候与天气适配

| 情况 | 规则 |
|---|---|
| 晨 / 午 | 面板 92% 不透明，文字影 `shadow-text` |

## 11. 文案规范

1. 数字与中文之间**空 1 格**：`第 1 天`、`钱 0 文`、`42 cm`。
2. 单位跟在数字后，不再空格：`0 文` 不是 `0文`；`42 cm` 里 cm 前有空格（拉丁单位按西文习惯）。
3. 表示"操作"的键名用键帽，不写成裸字；正文里提到键时用 `[T]` 形式。
4. 省略号统一用 `……`（六点），不用 `...`。
5. 感叹号一屏最多一个（`咬钩了！按 空格`）。
6. 书名/信封等用 `「」`，不用引号嵌套。
7. 所有文案必须来自真实文案表（§12），**不许**出现"适当调整""看情况"这类指示性文字。

## 13. Godot 实现映射

| 设计件 | Godot |
|---|---|
| 面板底 + 描边 | `StyleBoxFlat`：`bg_color` = ink @ alpha；`border_width_left=2`，其余 `1`；`border_color` = copper-a42；`corner_radius_* = 3`；`shadow_size=18`，`shadow_color`=black 45% |
| 字体 | `theme.default_font` = 界面族 18；叙事件单独 `font` override 指向衬线字体资源 |
| 字号/颜色 | Theme 里建 `font_size` 变体（`Label/Display`、`Label/H2`…），不要在代码里逐个 `add_theme_font_size_override` |
| 键帽 | `Button` + Theme 变体 `Keycap`：`StyleBoxFlat` 底/边/圆角，`content_margin_*` = 6/0，字 `micro` |
| 操作条 | `HBoxContainer`（gap 16）+ 每组 `HBoxContainer`（gap 4） |
| 状态行 | 单个 `RichTextLabel` 用 BBCode 分段（`[color]` + `[font_size]`），比多 Label 好对齐 |
| 瞬时大字 | `Label` + `Tween`（`modulate:a`、`position:y`），`hold` 用 `await get_tree().create_timer(2.2)` |
| 对话面板 | `Panel` + 两 `Label`；说话人名颜色代码里按 NPC/玩家切换 |
| 信纸 | 独立 `CanvasLayer(45)`；`Panel` 用渐变 `StyleBoxFlat` 做不到渐变 → 用 `TextureRect` + 1px 边 |
| 暂停 | `CanvasLayer(50)`；`PopupPanel` 自绘；焦点用 `Button` 的 `focus` StyleBox |
| 鱼篓 | `CanvasLayer(40)` + `ScrollContainer`（`vertical_scroll_mode = SCROLL_MODE_AUTO`） |
| 焦点 | Theme `focus` StyleBox：1px copper-a72 + shadow 2px copper 18% |

必须**代码画**（不要用 NinePatch 硬凑）：信纸的叠边、结算卡的新记录角标、抽屉的左侧双线。

## 14. 验收清单（实现完成逐条量）

1. 所有面板左描边 2px、上右下 1px，逐个数。
2. 所有坐标与间距是 4 的倍数；圆角只有 3 / 2 / 999。
3. 字号只出现 12/14/16/18/22/26/34 七种；`grep -r "font_size"` 核对。
4. 状态行、单位字号差一级（22 vs 14），基线对齐。
5. 三种说话人态（NPC/玩家/无）颜色各不相同且只有铜与海蓝两色。
6. 信纸是唯一的浅色面，纸上无铜、无海蓝。
7. 结算卡停留 ≥ 2.6s，任意键可立刻收起。
8. 暂停五项，焦点条 3px，滑块可拖，退出需确认。
9. 鱼篓空态、满态（11 行）、溢出滚动三种都截过图。
10. 夜/雾/黄昏三种天候下，每个文字仍可读（截图对照）。
11. 1280×720 与 1920×1080 下无布局跳位（`canvas_items` 缩放）。
12. 键帽在四种状态下（默认/按下/悬停/禁用）都有样子。
