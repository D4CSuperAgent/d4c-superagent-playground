## 三、现存缺失（设计的主要发挥空间）

项目里**没有**这三样，但玩法已经需要了：

1. **钓到鱼的结算卡**——现在只是一行 `钓到 %s（%d cm）　鱼篓 %d 条` 的大字，一闪就过，玩家来不及看清。
2. **暂停 / 设置**——ESC 直接退出游戏，没有确认、没有音量、没有操作说明。
3. **鱼篓 / 物品栏**——鱼篓里有什么、哪条能卖多少，现在完全看不见，只有一个条数。

## 四、全部瞬时文案（设计时要用真实文案，别用占位符）

**岸上**

- 走近 NPC 主动搭话（台词按 NPC 与日期变化，面板显示）
- `按 F 把鱼送给 %s`
- `%s 收过你的%s了　按 F 再送一条`
- `卖了 %d 条，得 %d 文　（共 %d 文）`
- `买了 5 个饵　饵 %d 个`
- `第 %d 天`
- `第 %d 天　有人把昨天的鱼用起来了`
- `按 E 上岸（鱼篓 %d 条　钱 %d 文）`

**海上**

- `按 空格 抛竿`
- `抛竿……`
- `等鱼上钩……（按 T 读信）`
- `咬钩了！按 空格`
- `跑了……按 空格 再抛一竿`
- `钓到 %s（%d cm）　鱼篓 %d 条`
- `船还在走，先停下来`
- `饵用完了，靠码头按 R 买（8 文 5 个）`
- `今天海上有雾，远处看不清`
- `再往外就只有雾了`
- `一群海豚贴着船边过去了`
- `海鸟 叼走了你的%s，留下一样东西：船舱里多了一封信（按 T 读）`

## 五、交互元素总表

| 元素 | 场景 | 现在有没有"看得见的样子" |
|---|---|---|
| WASD / 方向键提示 | 岸上、海上 | 只有一行文字，没有按键图形 |
| F 送鱼 | 岸上 | 只有 prompt 一行字 |
| E 卖鱼 / 上船 / 上岸 | 岸上、海上 | 只有 prompt 一行字 |
| R 买饵 | 岸上、海上 | 只有 prompt 一行字 |
| 空格 抛竿 / 收线 | 海上 | 只有居中大字 |
| T 读信 / 翻页 | 海上 | 只有页脚一行 `（T 翻页 1/3）` |
| ESC 退出 | 海上 | 只有顶部一行字，没有确认 |

**也就是说：这个游戏现在一个按钮都没有，全部交互靠"一行字告诉你按哪个键"。** 这也是为什么需要一个真正的 UI 层：按键要不要做成图标、要不要有统一的操作提示条、瞬时反馈和常驻状态怎么分层，都得有个说法。
